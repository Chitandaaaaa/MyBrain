# _template/ —— UI 资产脚手架

**这是一个模板，不是资产。新增一套 UI 时：复制本文件夹 → 改名为 `../<asset-id>/` → 按 STANDARD.md 第 8 节填写。不要直接在本目录里改。**

## 内部文件清单

| 文件 | 作用 | 必填 |
|---|---|---|
| `meta.json` | 溯源与元数据（机器可读） | ✅ |
| `index.html` | 展示台：预览 + 一键复制代码 | ✅ |
| `tokens.css` | 设计令牌（颜色/字体/字阶/间距/圆角/阴影） | ✅ |
| `components.css` | 组件样式 | ✅ |
| `notes.md` | 拆解与说明（按 STANDARD.md 第 5 节） | ✅ |
| `cover.png` | 预览缩略图（1200×750，放上层目录） | ✅ |
| `original/` | 原件备份（原站 HTML / 截图 / 源文件） | ✅ |
| `fonts/` | 本地化字体 woff2（可选） | ⚠️ |

## 命名速记
- 文件夹名：`kebab-case` 全小写英文/拼音，见名知意。
- 中文名只写在 `meta.json` 的 `name`，不进路径。
- 内部文件名严格如上，不要自由发挥。

完整标准见同级 `../STANDARD.md`。
