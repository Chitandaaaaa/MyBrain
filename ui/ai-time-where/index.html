这套 UI 是什么风格

不是组件库，是纯手写 CSS。全站没有一个框架、没有一个 UI 库（没有 Tailwind、没有 shadcn、没有 Bootstrap）， 一共 196 行手写样式，靠 5 个颜色 + 3 套字体 + 1 张网格纸底纹就把气质做出来了。

风格可以叫「中文复古印刷海报」：Risograph（丝网印）式的低饱和配色、纸感底色、方格稿纸纹理、 手写行楷当分类标签、硬边投影的按钮，再加上超大号的窄体数字。

  • 纸底 #fbf8f5 不用纯白
  • 墨色 #132b69 不用纯黑
  • 只有一个行动色
  • 描边替代投影
  • 手写体做标签

    配色

    点任意色块复制 HEX

    主色只有 5 个，克制是这套设计能显高级的原因：一个暖白纸底、一个藏青墨、一个焦橘当唯一行动色、一个深枣红只用来做按钮投影、一个芥末黄做高亮。

    分类色 · 9 类

    分类色故意做成「印刷油墨」式的低饱和：没有一个霓虹色，饱和度都压在 45–60%，这样 9 个颜色并排堆在一条堆叠条上也不打架。

    堆叠条 · 斜纹流动

    色块上盖一层 repeating-linear-gradient(115deg, rgba(255,255,255,.07)) 的斜纹并让它缓慢流动，大色块就不闷了；整条外层加 drop-shadow(0 10px 0) 做纸张厚度。

    ⚠️ 这里有个必踩的坑：颜色必须写 background-color，不能写 background。
    background 是简写属性，会连带把 background-image 重置成 none —— 斜纹和流动动画会在你眼皮底下凭空消失，而且不报错。
    原站原值 · 白 7% / 18s 走 400px（几乎看不出，只让色块不死板）
    加强对照 · 白 22% / 4s（只为让你看清斜纹和流动方向）

    原站故意做得极淡：7% 的白、18 秒才走 400px。它的作用不是「装饰动画」，而是给大色块加一层油墨纹理，让色块看起来是「印上去的」而不是「填色」。想要更明显，把透明度提到 .16–.22、时长缩到 6s 左右即可。

    文案

    标题与副标

    页面标题：AI 时间都去哪了 · 会话分类统计
    一句简介：读取本机 WorkBuddy 会话记录，把 AI 使用时间按闲聊 / 修复BUG / 搭建环境 / 测试Skill&MCP / 搜索信息 / 工作 分类统计。全部在浏览器本地解析，数据不上传。

    9 个分类名

    闲聊修复BUG搭建运行环境 测试技能搜索信息图片创作 视频创作写小说工作

    注意命名口径：动词开头、不缩写（「搭建运行环境」而不是「环境」），「修复BUG」保留英文大写——这比清一色的四字词更像真人写的。

    口径说明（这段写法最值得学）

    这里算的不是「窗口开了多久」，而是「你真正在跟它来回折腾了多久」：把相邻两条消息的间隔加起来，单段最多算 90 分钟就当你人走了，那段时间不计入。

    句式是「不是 A，而是 B」+ 具体数字 + 口语化比喻（「当你人走了」）。解释一个统计口径最怕写成技术文档，这样写反而更可信。

    分类是按每一轮分别判的：一条会话里先装环境、后做视频，时间会分别记到两类名下，不会整条贴一个标签。

    每天一根柱子，颜色就是当天的分类构成。空白的日子是真没在用（不是加载失败）。

    括号补一句「不是加载失败」—— 预判了用户的怀疑。这种小补丁是产品感的关键。

    05

    抄这套 UI 时最容易漏掉的 6 个细节

    1. 圆角很大但阴影很薄：卡片 22px 圆角，却只用 inset 0 0 0 1px #132b6912 描边，不用大面积投影。所以轻盈。
    2. 透明度写死成十六进制：全站没有 rgba()，一律 #132b69cc / #132b6980 这种写法，一个墨色靠 alpha 派生出整条灰阶。
    3. 纸底从不纯白：卡片是 #ffffffd9（白 85%），让底下的网格纸纹透上来一点点。
    4. 网格 28px：线宽 1px、墨色 5%。28 是个不上不下的数字，正好不和常见的 24/32 撞。
    5. 数字用 tabular-nums：font-variant-numeric:tabular-nums，跳动时不抖。
    6. 手写体只做「标签」不做「正文」：Long Cang 只出现在分类名和批注上，正文一律无衬线。手写体一多就土。

    怎么用这个目录

    ui-kit.css —— 提炼好的设计系统，直接 <link> 进你自己的页面就能拿到全部样式和令牌。

    original.html —— 原作品完整单文件备份（含全部 HTML/CSS/JS，65KB）。页面靠 JS 读取本地 WorkBuddy 会话记录，所以单独打开会停在「选择目录」那一步，但所有样式和交互代码都在里面。

    fonts/ —— Khand、Hind 的本地 woff2（latin 子集）。Long Cang 与 Noto Sans SC 走 Google Fonts 链接，并用 华文行楷 / 苹方 兜底。
