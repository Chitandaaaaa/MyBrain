# MyBrain

记录日常的学习内容和一些数字资产。

## 目录结构

```
MyBrain/
├── README.md
├── 随手记.md
└── ui/                       # 个人 UI 参考资产库
    ├── README.md             # 资产总览索引（资产表 + 标签 + 如何新增）
    ├── STANDARD.md           # UI 资产库总标准（组件清单、命名、溯源、评审）
    ├── _template/            # 新增资产脚手架（复制改名即用）
    └── ai-time-where/        # 资产示例：中文复古印刷数据看板（risograph）
```

> `ui/` 下每套 UI 一个文件夹，按 [ui/STANDARD.md](./ui/STANDARD.md) 组织；新增资产复制 `ui/_template/` 后改名填写。
