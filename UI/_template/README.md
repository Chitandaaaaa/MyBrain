# _template/ —— UI 资产脚手架

**这是一个模板，不是资产。新增一套 UI 时：复制本文件夹 → 改名为 `../<风格名>/` → 按 STANDARD.md 第 8 节填写。不要直接在本目录里改。**

## 内部文件清单

| 文件 | 作用 | 必填 |
|---|---|---|
| `meta.json` | 溯源与元数据（机器可读） | ✅ |
| `index.html` | 展示台（临摹台）：预览 + 一键复制代码 + 解释 | ✅ |
| `ui-kit.css` | 设计令牌（颜色/字体/字阶/间距/圆角/阴影）+ 基础原语 | ✅ |
| `ui-components.css` | 具体组件样式（基于令牌；组件 id 对齐 STANDARD 第 3 节） | ✅ |
| `design-system.md` | 设计系统文档：令牌层 + 组件层 + 签名组件小节（按 STANDARD 第 5 节） | ✅ |
| `showcase-components.html` | 【可选】通用原语货架（纯通用件，**不含签名件**） | ⚠️ |
| `cover.png` | 预览缩略图（1200×750，放上层目录） | ✅ |
| `original/` | 原件备份（原站 HTML / 截图 / 源文件） | ✅ |
| `js/` | 【可选】需测量才能画对的组件脚本（图表标注/拖拽/瀑布流） | ⚠️ |
| `fonts/` | 本地化字体 woff2（可选） | ⚠️ |

## 命名速记
- **文件夹名 = 风格名**：用这套 UI 最定义性的风格命名（中文或 kebab-case 英文都行，如 `丝网印手绘` / `glassmorphism`），**不要用项目名 / 源站名**。详见 STANDARD §1.3。
- 中文名只写在 `meta.json` 的 `name`，不进路径。
- 内部文件名严格如上，不要自由发挥（如别把 `ui-kit.css` 叫 `tokens.css`、别把 `design-system.md` 叫 `说明.md`）。
- 组件 `id` 统一用 STANDARD.md 第 3 节「组件注册表」的英文名，新通用组件先去那里登记再写。

完整标准见同级 `../STANDARD.md`。
