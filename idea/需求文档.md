# MyBrain 灵感收纳 · 需求文档

> 版本：v0.3（Demo 原型 · 响应式工作台：移动端单输入框 + PC 检索归档）
> 日期：2026-11-03
> 状态：原型已实现，可本地运行

## 1. 产品方向（已更新）
MyBrain 是一个**移动端优先、桌面端增强的个人灵感速记工具**。用户只需要一个输入框——直接打字，或按住说话——提交后由**可配置的 AI** 自动判断内容类型、提炼标题/标签/来源，并写入「仓库」。原则是 **Capture now, organize later**：录入极简，整理交给 AI。

- **入口形态**：移动端网页（单页、单输入框，极简）；PC 端自动展开为「工作台」双栏（左侧速记+筛选，右侧搜索+列表）。
- **输入方式**：文字输入 或 语音输入（二选一，不堆选项）。
- **智能化**：提交后 AI 自动归类入库；AI 由用户本地配置（OpenAI 兼容接口），不做平台绑定。
- **零门槛录入 + 强检索归档**：移动端只负责"说/写"；想法变多后，在 PC 工作台通过**搜索 / 类型筛选 / 标签筛选 / 归档**高效管理。

## 2. 目标用户与使用场景
- **人群**：经常有零散想法、爱摘抄、做内容 / 产品 / 创作的人。
- **场景**：
  - 走路时脑子冒出点子 → 语音说一句 → AI 归为「想法」入库。
  - 看书看到好句子 → 直接粘贴/口述 → AI 识别为「摘抄」并补全来源。
  - 想找某条 → 在仓库按类型 / 标签 / 关键词回溯。

## 3. 项目专有名词约定（Glossary）
为避免协作中"一会一个叫法"，统一如下，文档与后续开发均以此为基准：

| 名词 | 英文 / 缩写 | 含义说明 | 示例 |
|------|------------|----------|------|
| 灵感 / 想法 | Idea | 用户自发产生的念头 / 感悟，文字记录 | "做个离线版？" |
| 摘抄 / 语录 | Quote | 来自外部、值得收藏的文字，含「来源」 | 书中一段话 |
| 语音速记 | Voice Note | 通过麦克风录入、经 AI 整理的内容 | 走路时说的灵感 |
| 备忘 | Note | 其它杂项记录 | 待办、提醒 |
| 条目 | Entry | 仓库中最小存储单位；任一记录即一条 Entry | — |
| 标签 | Tag | 用户/AI 为条目打的归类关键词，可多个 | #产品 #灵感 |
| 速记 | Quick Capture | 录入新条目的动作 / 界面（单输入框） | 说一句 |
| 仓库 | Vault | 所有已存条目的集合与浏览界面 | 列表页 |
| 回溯 / 回看 | Review | 在仓库中搜索、筛选、重看已有条目 | 搜"离线" |
| 来源 | Source | 摘抄类条目的出处（书名 / 作者 / 链接） | 《xxx》 |
| AI 归类 | AI Classify | 提交后由 AI 判断类型并结构化提炼 | 返回 JSON |
| 配置 / 接入 | Config | 用户填入本地 AI 的地址/Key/模型 | localhost:8000 |
| 兜底分类 | Fallback | 未配置/AI 失败时用的本地规则归类 | 含 http→摘抄 |
| 语音转写 | Transcription | 语音转成文字的过程（浏览器或 AI 完成） | — |
| 工作台 | Workbench | PC 端响应式布局：左栏速记+筛选，右栏搜索+列表 | 双栏界面 |
| 收件箱 | Inbox | 未归档条目的集合视图（nav=inbox），保持活跃区清爽 | 默认视图 |
| 归档 | Archive | 将条目移出收件箱的动作/状态（archived=true），便于长期收纳 | 点「归档」 |
| 搜索 | Search | 跨标题/内容/标签/来源的实时关键词过滤 | 顶部搜索框 |

> 约定：代码变量尽量与上表对应（`idea`/`quote`/`voice`/`note`/`entry`/`tag`/`vault`/`review`/`source`/`config`）。

## 4. 功能需求
| 编号 | 名称 | 描述 | 优先级 |
|------|------|------|--------|
| FR-01 | 单输入框录入 | 一个对话框同时支持文字输入与语音输入，无多余选项 | P0 |
| FR-02 | 语音输入 | 点击麦克风说话，实时转写或录音后上传 AI | P0 |
| FR-03 | AI 自动归类 | 提交后调用配置的 AI，返回类型/标题/标签/来源并入库 | P0 |
| FR-04 | AI 可配置 | 设置中填写 API 地址 / Key / 模型 / 语音模式，本地持久化 | P0 |
| FR-05 | 仓库列表 | 时间倒序展示所有 Entry，含类型标识与时间 | P0 |
| FR-06 | 类型筛选 | 按 全部/想法/摘抄/语音/备忘 过滤（侧栏带计数） | P1 |
| FR-07 | 关键词搜索 | 顶部搜索框实时跨标题/内容/标签/来源过滤 | P1 |
| FR-08 | 删除条目 | 可删除单条 Entry（带确认） | P1 |
| FR-09 | 本地持久化 | 数据存浏览器 IndexedDB，无需登录 | P0 |
| FR-10 | 兜底分类 | 未配置/AI 失败时用本地规则归类，保证可用 | P2 |
| FR-11 | 归档管理 | 条目支持「归档/取消归档」；收件箱仅显示未归档，已归档独立视图 | P1 |
| FR-12 | 标签云筛选 | 侧栏按使用频次展示标签，点击即筛选对应条目 | P1 |
| FR-13 | 响应式布局 | 移动端单列极简；PC（≥820px）展开为双栏工作台 | P1 |

## 5. 非功能需求
- NFR-01 响应式：移动端单列极简（单输入框）；桌面（≥820px）展开为双栏工作台（速记+筛选 / 搜索+列表）。
- NFR-02 零登录、零后端依赖：纯前端运行；AI 由用户自备。
- NFR-03 极低录入阻力：打开即用，录入不超过 2 步。
- NFR-04 隐私：文本/语音不上传第三方，仅发往用户配置的 AI。

## 6. AI 接入约定（OpenAI 兼容）
- **接口**：`${apiBase}/chat/completions`（如 `http://localhost:8000/v1`）。
- **请求**：标准 chat completions；system 提示要求只返回 JSON；可选 `response_format:{type:"json_object"}`。
- **返回契约**（结构化）：
  ```json
  {
    "type": "idea | quote | voice | note",
    "title": "简短标题",
    "content": "整理后的正文",
    "tags": ["标签1", "标签2"],
    "source": "来源，无则空字符串"
  }
  ```
- **语音模式**：
  - `recorder`（默认）：MediaRecorder 录音 → 停止后送 AI 转写+分类（全浏览器可用）。
  - `speech`：浏览器 Web Speech 实时转写 → 文本送 AI 分类（仅 Chrome/Edge，需联网）。
- **兜底**：未配置或解析失败时，按本地规则归类（含 http/《/“ 等特征→摘抄，否则想法）。

## 7. 数据模型（Entry）
```text
Entry {
  id:        string              // 唯一 ID
  type:      'idea'|'quote'|'voice'|'note'
  title:     string              // AI 提炼的标题
  content:   string              // 正文（语音为转写/整理文本）
  tags:      string[]            // 标签
  source:    string              // 摘抄来源
  archived:  boolean            // 是否归档（false=收件箱，true=已归档）
  pending:   boolean             // 是否正在 AI 处理中
  createdAt: number              // 时间戳
}
```
存储：浏览器 IndexedDB，object store `entries`，按 `createdAt` 倒序读取。

## 8. 原型范围与已知边界
- **已实现**：FR-01~10 的基础能力（本地版）。
- **暂不包含**：账号体系、多端同步、云备份、富文本、导出、原始音频回放。
- **限制**：语音实时转写依赖 Chrome/Edge 的 Web Speech；清空浏览器数据会丢失记录。

2. 云端同步与多设备；移动端原生 App 封装。
3. AI 自动生成「每日灵感日报」、主题聚合。
